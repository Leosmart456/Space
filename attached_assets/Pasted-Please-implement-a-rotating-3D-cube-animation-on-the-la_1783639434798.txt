Please implement a rotating 3D cube animation on the landing page in the brokers list section.

Each face of the cube should display a broker logo (e.g., Schwab, Interactive Brokers, Robinhood, Moomoo, CMC Markets, Fidelity).

The cube should continuously rotate using CSS @keyframes with transform: rotateX and rotateY.

Use transform-style: preserve-3d and translateZ to position each face correctly.

The cube should be responsive (150px–200px size) and centered in its container.

On hover, the cube should pause rotation.

Place 3–4 cubes in a row/grid to showcase multiple brokers.

Ensure logos are scaled proportionally inside each face (max-width: 80%).

Wrap the cube(s) inside a #brokers-list section so they can be styled consistently with the rest of the landing page.

✅ Example Code Snippet (for them to adapt)
html
<section id="brokers-list">
  <div class="cube">
    <div class="face front"><img src="schwab.png"></div>
    <div class="face back"><img src="ib.png"></div>
    <div class="face right"><img src="robinhood.png"></div>
    <div class="face left"><img src="moomoo.png"></div>
    <div class="face top"><img src="cmc.png"></div>
    <div class="face bottom"><img src="fidelity.png"></div>
  </div>
</section>
css
.cube {
  width: 150px;
  height: 150px;
  position: relative;
  transform-style: preserve-3d;
  animation: spin 10s infinite linear;
  margin: 20px;
}
.face {
  position: absolute;
  width: 150px;
  height: 150px;
  display: flex;
  align-items: center;
  justify-content: center;
}
.face img { max-width: 80%; max-height: 80%; }
.front  { transform: rotateY(0deg) translateZ(75px); }
.back   { transform: rotateY(180deg) translateZ(75px); }
.right  { transform: rotateY(90deg) translateZ(75px); }
.left   { transform: rotateY(-90deg) translateZ(75px); }
.top    { transform: rotateX(90deg) translateZ(75px); }
.bottom { transform: rotateX(-90deg) translateZ(75px); }
@keyframes spin {
  from { transform: rotateX(0deg) rotateY(0deg); }
  to   { transform: rotateX(360deg) rotateY(360deg); }
}
.cube:hover { animation-play-state: paused; }
